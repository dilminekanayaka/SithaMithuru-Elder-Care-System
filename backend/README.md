# SithaMithuru Backend

Node.js backend server for the SithaMithuru Elder Care System.

## Project Structure

```
backend/
├── src/
│   └── server.ts               # Server entry point (placeholder)
├── tests/                      # Test directory
├── package.json                # Dependencies
├── tsconfig.json              # TypeScript config
└── README.md                  # This file
```

## Setup & Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
